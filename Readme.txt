Budget Tracker System

This project is a console-based Personal Budgeting System developed for the Software Engineering course.

Project Contents:
--------------------------------------------------

1. src/
Contains all Java source code files for the system implementation.

2. docs/
Contains the generated JavaDoc documentation files.

3. SDS.pdf
Contains the Software Design Specification document including:
- Architecture Diagram
- Class Diagram
- Sequence Diagrams
- State Diagram
- SOLID Principles
- Design Patterns

4. Presentation.pdf
Contains the project presentation slides.

5. GitHubScreenshots/
Contains screenshots of the GitHub repository and commits.

Tools Used:
--------------------------------------------------
- Java
- IntelliJ IDEA
- PlantUML
- Draw.io
- GitHub

System Features:
--------------------------------------------------
- User Registration and Login
- Expense Management
- Budget Tracking
- Expense Reports
- File Persistence using Database.json

Notes:
--------------------------------------------------
- The project uses JavaDoc for code documentation.
- No executable (.exe) or (.jar) files are included as required.
